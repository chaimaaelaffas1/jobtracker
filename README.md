# JobTracker

**JobTracker** est une application web qui permet de suivre, organiser et gérer ses candidatures d'emploi depuis un seul endroit.

## 🎯 Objectif du projet

Créer une application Full Stack pour faciliter le suivi de la recherche d'emploi et garder une trace de toutes les candidatures.

## ✨ Fonctionnalités prévues

- [ ] Ajouter une nouvelle candidature.
- [ ] Afficher la liste de toutes les candidatures.
- [ ] Modifier les informations d'une candidature.
- [ ] Supprimer une candidature.
- [ ] Suivre le statut de chaque candidature :
  - À postuler
  - Envoyée
  - Entretien
  - Offre
  - Refusée
- [ ] Enregistrer la date de candidature.
- [ ] Ajouter le lien de l'offre d'emploi.
- [ ] Ajouter des notes personnelles pour chaque candidature.
- [ ] Afficher des statistiques :
  - Nombre total de candidatures.
  - Nombre de candidatures envoyées.
  - Nombre d'entretiens.
  - Nombre d'offres reçues.

## 🛠️ Technologies prévues

- **Frontend :** HTML, CSS, JavaScript, React et Tailwind CSS.
- **Backend :** Python et FastAPI.
- **Base de données :** À définir.
- **Gestion de versions :** Git et GitHub.
